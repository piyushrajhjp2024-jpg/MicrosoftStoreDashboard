## 📖 Project Overview

This project is an AI-powered dashboard that fetches Google Play Store reviews in real time and performs sentiment analysis using Hugging Face Transformers.

The dashboard provides interactive visualizations to help understand customer opinions and application performance.

---

## ✨ Features

- 📥 Real-time Google Play Store Reviews
- 🤖 AI Sentiment Analysis
- 📊 Interactive Dashboard
- 📈 Sentiment Trend Analysis
- 🥧 Pie Chart Visualization
- ☁️ Word Cloud
- 🔍 Top Customer Issues Detection
- ⭐ Average Rating
- 📄 PDF Report Generation
- 📥 CSV Download
